# 🛠️ My Arduino & Robotics Projects

ยินดีต้อนรับสู่คลังเก็บรวบรวมโปรเจกต์สิ่งประดิษฐ์และระบบสมองกลฝังตัว (Embedded System) ที่พัฒนาขึ้นโดยใช้ Arduino และเซนเซอร์ต่างๆ เพื่อแก้ไขปัญหาและประยุกต์ใช้งานจริง

## 📁 รายชื่อโปรเจกต์ในคลังนี้ (Project Repository)

### 1. ถังขยะอัตโนมัติ (Automatic Trash Bin)
* **ไฟล์โค้ด:** automatic-trashbin.ino
* **รายละเอียดโปรเจกต์:** ระบบเปิด-ปิดฝาถังขยะอัตโนมัติโดยไม่ต้องสัมผัส เพื่อสุขอนามัยที่ดีและลดการแพร่กระจายของเชื้อโรค
* **อุปกรณ์หลักที่ใช้:** 
  * บอร์ด Arduino (Uno / Nano)
  * เซนเซอร์ตรวจจับวัตถุ Ultrasonic Sensor (HC-SR04) สำหรับวัดระยะห่างของมือ
  * เซอร์โวมอเตอร์ (Servo Motor) สำหรับควบคุมการเปิด-ปิดฝาถังขยะ

### 2. รถเดินตามเส้นและหลบหลีกสิ่งกีดขวาง (Mecanum Car Line Tracking & Ultrasonic)
* **ไฟล์โค้ด:** mecanum-car-line-tracking-and-ultrasonic-sensor.ino
* **รายละเอียดโปรเจกต์:** หุ่นยนต์เคลื่อนที่สี่ล้อแบบ Mecanum Wheel ที่มีความสามารถในการเคลื่อนที่รอบทิศทาง โดยพัฒนาระบบให้เดินเคลื่อนที่ตามเส้นทางที่กำหนดควบคู่ไปกับระบบความปลอดภัยอัจฉริยะหลบหลีกสิ่งกีดขวาง
* **อุปกรณ์หลักที่ใช้:**
  * บอร์ดไมโครคอนโทรลเลอร์ Arduino
  * ล้อและโครงรถ Mecanum Wheel Car Chassis พร้อม Motor Driver
  * เซนเซอร์อินฟราเรด (Infrared Tracking Sensor) สำหรับตรวจจับเส้นทาง
  * เซนเซอร์ Ultrasonic (HC-SR04) สำหรับตรวจจับและหลบหลีกสิ่งกีดขวางด้านหน้า

* **Programming:** การเขียนโปรแกรมควบคุมไมโครคอนโทรลเลอร์ด้วยภาษา C/C++ (Arduino IDE)
* **Hardware Integration:** การต่อวงจรอิเล็กทรอนิกส์, การคำนวณและจ่ายไฟให้มอเตอร์, การอ่านค่าจากเซนเซอร์รูปแบบต่างๆ
* **Robotics & Control:** เข้าใจกลไกการเคลื่อนที่ของล้อ Mecanum และหลักการทำงานของระบบอัตโนมัติ (Automation)
